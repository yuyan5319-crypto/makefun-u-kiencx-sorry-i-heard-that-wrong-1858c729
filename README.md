Sorry, I Heard That Wrong: one original line — the apology a smart speaker gives after mishearing "dim the lights" as "book a flight", and trying to sell the mistake instead of owning it.

> Sorry — you said 'dim the lights', I heard 'book a flight', and the Lisbon sunset this time of year is honestly gorgeous.

## Run it

```sh
node main.ts
```

The program writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and prints it to stdout. It refuses to run if the line is not 1–140 characters, so the gate can never see an invalid entry.
